## 📥 Download & Install

### System Requirements
- **OS:** Windows 10 / 11 (64-bit)
- **Browser:** Chrome, Edge, or Firefox (latest version)
- **Account:** Active LinkedIn Learning subscription

### Installation
1. **Download** `LLDInstallerV2.0.exe` from the [Releases](../../releases) page
2. **Run** the installer and follow the setup wizard
3. **Launch** from your desktop shortcut or Start Menu

> [!IMPORTANT]
> If you have V1.4 installed, please **uninstall it first** before installing V2.0. The old version is fully deprecated and no longer functional.

## ❓ FAQ

<details>
<summary><b>Is this tool free?</b></summary>
<br>
Yes, LinkedIn Learning Downloader is completely free to use. You need your own active LinkedIn Learning subscription.
</details>

<details>
<summary><b>Is my LinkedIn account safe?</b></summary>
<br>
Yes. The tool uses your existing browser session for authentication. Your credentials are never stored or transmitted to any third party.
</details>

<details>
<summary><b>Why is the source code not available?</b></summary>
<br>
To prevent misuse and exploitation. The compiled binary is distributed as a professional installer for end users.
</details>

<details>
<summary><b>V1.4 stopped working — what happened?</b></summary>
<br>
V1.4 was permanently retired due to a critical infrastructure failure. V2.0 is a complete rewrite with a more resilient, self-contained architecture.
</details>
